# Support

This is a free, open-source, community-driven project maintained in spare time — there is no paid support tier, no SLA, and no dedicated support staff.

## Getting help

- **Something's broken?** Open a [bug report](.github/ISSUE_TEMPLATE/bug_report.md) via [GitHub Issues](https://github.com/pypi-ahmad/codebase-understanding-agent/issues).
- **Have a question about using the app?** Check [USAGE.md](USAGE.md) first — it has a full walkthrough plus a troubleshooting table mapping error messages to fixes. If it's still unclear, open an issue; questions are welcome, not just bug reports.
- **Want a new feature?** Open a [feature request](.github/ISSUE_TEMPLATE/feature_request.md).
- **Found a security issue?** See [SECURITY.md](SECURITY.md) — please don't report those as regular issues.

## What to expect

Responses come as time allows — there's no guaranteed turnaround. Well-described issues (steps to reproduce, the exact error message, your environment) get resolved faster simply because there's less back-and-forth needed.

## No financial support needed or wanted

This project does not want or accept donations, sponsorships, or any other financial support, and never will. It costs nothing to use and nothing to maintain beyond time. If you want to give back, the most helpful things you can do are: report bugs clearly, suggest features, improve the docs, or contribute code — see [CONTRIBUTING.md](CONTRIBUTING.md).
