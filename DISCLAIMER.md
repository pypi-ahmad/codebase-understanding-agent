# Disclaimer

Please read this before pointing the app at any codebase, especially one that isn't entirely your own.

## You run this entirely on your own machine, with your own credentials

Codebase Understanding Agent is a local tool. There is no hosted version, no backend server operated by the author, and no account system. You run it on your own machine using `uv`, and you supply your own API key(s) for whichever LLM provider(s) you choose (OpenAI, Google Gemini, Agnes AI) or your own local Ollama server. See [README.md](README.md#environment-variables).

## You are 100% responsible for the data you feed into it

Whatever you point the app at — a GitHub URL, a local folder, or an uploaded zip — its file tree and the text content of the files it picks as "key files" are sent to whichever LLM provider you've configured, so it can generate summaries and answer your questions (see [ARCHITECTURE.md](ARCHITECTURE.md) for exactly how). **You, and only you, are responsible for:**

- Making sure you're allowed to share that code with a third-party AI provider — this includes your employer's code, client code, code under a license that restricts this, and any code containing secrets, credentials, personal data, or other sensitive content.
- Understanding and accepting your chosen provider's own data-handling, retention, and training-use policies (OpenAI's, Google's, Agnes AI's — whichever you use). This project has no control over, and makes no claims about, what any third-party provider does with data sent to it.
- Any costs your provider charges you for API usage. This project does not meter, cap, warn about, or reimburse API spend.

**If your data must never leave your machine**, use the **Ollama** fast-model option — it's the only path in this app that doesn't send file content to a remote third party (the strong model still requires OpenAI, Agnes AI, or Gemini today; see [README.md](README.md#configuration-options)).

## AI-generated output can be wrong

File summaries, the architecture write-up, and chat answers are all generated by an LLM. They are not verified for correctness by this project. Treat them as a starting point for understanding a codebase, not as a source of truth — always verify anything important against the actual source code.
